## 👩🏽‍💻 Minha Contribuição – DIO Open Source Lab  

Este projeto faz parte do desafio **"Contribuindo em um Projeto Open Source no GitHub"**, realizado durante o **Bootcamp Ri Happy - Front-End do #2**, promovido pela [Digital Innovation One (DIO)](https://www.dio.me).  

Durante o lab, aprendi na prática como funciona o processo de contribuição em um projeto Open Source, utilizando o GitHub como ferramenta de colaboração.  
Minha contribuição consistiu em **criar e adicionar meu próprio Profile README** no repositório `digitalinnovationone/dio-lab-open-source`, aplicando conceitos como **fork, commit e pull request**.  

#### 🚀 Resultado  
Essa experiência me ajudou a compreender o funcionamento da comunidade open source, fortalecer meus conhecimentos em versionamento e dar meu primeiro passo colaborando com outros desenvolvedores.
